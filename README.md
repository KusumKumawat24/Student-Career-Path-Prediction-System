# 🎓 Student Career Path Prediction System

## 📌 Project Overview

The **Student Career Path Prediction System** is a Machine Learning-based web application designed to help students identify suitable career paths based on their skills, interests, academic background, and other relevant factors.

The system uses a trained Machine Learning model to predict a suitable career option from the information provided by the user.

The project provides an interactive and user-friendly interface developed using **Streamlit**.

---

## 🚀 Features

- 🎓 Student career prediction
- 🤖 Machine Learning-based prediction
- 🖥️ Interactive Streamlit web interface
- 📊 Data-driven career recommendations
- 📁 Trained model saved using Pickle
- 🔍 User-friendly input fields
- ⚡ Fast prediction results
